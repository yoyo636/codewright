Features

Everything you need to
ship faster

Purpose-built for real development workflows. Not a chatbot with a code editor attached.

Two Built-in Agents

Switch with Tab: build for full-access development, plan for read-only analysis and exploration.

Subagents

Delegate complex searches and multi-step tasks with @general. Parallel execution, isolated context.

Tools & Extensibility

Built-in file, shell, and web tools. Extend with MCP servers (OAuth supported) and plugins for infinite capability.

Persistent Sessions

Conversations that last. Continue, resume by ID, or fork any session. Your context is never lost.

Fine-grained Permissions

Control exactly which tools and commands may run. Stay in charge of what touches your system.

Runs Everywhere

Terminal TUI, desktop app (macOS/Windows/Linux), web interface, and headless mode for CI/CD pipelines.

How it works

From prompt to shipped
in four steps

Codewright plans, reads, acts, and verifies — autonomously, with you in control.

STEP 01
🎯

Understand the ask

Explain the goal in plain language. Codewright reads your codebase to build a mental model before acting.

STEP 02
🔍

Investigate broadly

Breadth-first exploration scans structure, configs, and entry points — using search tools to keep context lean.

STEP 03
⚙️

Execute with tools

File edits, shell commands, diffs, and tests — chained together, with permission prompts at every boundary.

STEP 04
✅

Verify & report

Runs lint and typecheck, confirms tests pass, and reports outcomes honestly — never claims success it didn't confirm.

Install

Build from source

Codewright is currently distributed as source. Clone, install with Bun, and link the yoyocode command. Prebuilt binaries will follow on GitHub Releases.

1 · Clone

$ git clone https://github.com/yoyo636/codewright.git

2 · Install deps

$ cd codewright && bun install

3 · Link globally

$ cd packages/opencode && bun link

4 · Run

$ yoyocode

Prebuilt binaries

GitHub Releases · coming soon
