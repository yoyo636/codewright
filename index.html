Features

Everything you need to
ship faster

Purpose-built for real development workflows. Not a chatbot with a code editor attached.

Two Built-in Agents

Switch with Tab: build for full-access development, plan for read-only analysis and exploration.

Subagents

Delegate complex searches and multi-step tasks with @general. Parallel execution, isolated context.

Tools & Extensibility

Built-in file, shell, and web tools. Extend with MCP servers (OAuth supported) and plugins for infinite capability.

Persistent Sessions

Conversations that last. Continue, resume by ID, or fork any session. Your context is never lost.

Fine-grained Permissions

Control exactly which tools and commands may run. Stay in charge of what touches your system.

Runs Everywhere

Terminal TUI, desktop app (macOS/Windows/Linux), web interface, and headless mode for CI/CD pipelines.

Developer Experience

Configure once,
control everything

A minimal config gets you started. A powerful schema lets you fine-tune every aspect of your AI coding workflow.

  • Instant Setup

    One command to start. Environment variables or interactive login.

  • Provider Agnostic

    Anthropic, OpenAI, OpenRouter, Google, and more. Bring your own API key.

  • Project-level Config

    Commit codewright.json to share team settings.
