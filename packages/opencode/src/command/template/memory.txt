Manage persistent memory for this user.

Persistent memories live in the file `~/.config/codewright/memory.md` (macOS/Linux) or the equivalent Codewright config directory on your platform. The current memory content is injected into your system prompt inside a `<memory>` block, which already tells you the exact path. This file should only contain durable, high-signal facts about the user's preferences, workflow, and long-lived decisions — not session trivia.

## Behavior

With no arguments, read the memory file and show its current contents to the user. Explain what is stored and where.

With `$ARGUMENTS` provided:
- If the user asks to add or remember something, append a concise, well-formatted entry to the memory file using the Edit tool. Prefer appending over rewriting.
- If the user asks to remove or forget something, edit the file to delete that specific entry.
- If the user asks to clear memory, empty the file (leave a short header comment).
- Otherwise, interpret the request and update the file accordingly.

## Format

Use clean Markdown:

# Memory

## <topic>
- concise, durable fact

Keep each entry to one or two lines. Merge duplicates instead of piling them up. Preserve the file's existing structure when you edit it.

## Rules

- Never store secrets, API keys, or credentials in memory.
- Never store project-specific code facts here — those belong in AGENTS.md.
- Only persist what the user explicitly asks to remember, or facts so stable and important they'd clearly help future sessions.
- After editing, briefly tell the user what you changed.
