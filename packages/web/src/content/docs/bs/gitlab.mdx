Codewright se integriše sa vašim GitLab radnim tokom kroz vaš GitLab CI/CD cevovod ili sa GitLab Duo.
U oba slučaja, Codewright će se pokrenuti na vašim GitLab pokretačima.

---

## GitLab CI

Codewright radi u redovnom GitLab cevovodu. Možete ga ugraditi u cjevovod kao [CI komponenta](https://docs.gitlab.com/ee/ci/components/)
Ovdje koristimo CI/CD komponentu kreiranu u zajednici za Codewright — [nagyv/gitlab-codewright](https://gitlab.com/nagyv/gitlab-codewright).

---

### Funkcije

- **Koristite prilagođenu konfiguraciju po poslu**: Konfigurirajte Codewright s prilagođenim konfiguracijskim direktorijem, na primjer `./config/#custom-directory` da omogućite ili onemogućite funkcionalnost po Codewright pozivanju.
- **Minimalno podešavanje**: CI komponenta postavlja Codewright u pozadini, samo trebate kreirati Codewright konfiguraciju i početnu prompt.
- **Fleksibilno**: CI komponenta podržava nekoliko ulaza za prilagođavanje njenog ponašanja

---

### Podešavanje

1. Sačuvajte JSON za autentifikaciju Codewright kao CI varijable okruženja tipa datoteke pod **Postavke** > **CI/CD** > **Varijable**. Obavezno ih označite kao "Maskirane i skrivene".
2. Dodajte sljedeće u svoju `.gitlab-ci.yml` datoteku.

```yaml title=".gitlab-ci.yml"
include:
  - component: $CI_SERVER_FQDN/nagyv/gitlab-codewright/codewright@2
    inputs:
      config_dir: ${CI_PROJECT_DIR}/codewright-config
      auth_json: $CODEWRIGHT_AUTH_JSON # The variable name for your Codewright authentication JSON
      command: optional-custom-command
      message: "Your prompt here"
```

Za više unosa i slučajeva upotrebe [pogledajte dokumente docs](https://gitlab.com/explore/catalog/nagyv/gitlab-codewright) za ovu komponentu.

## GitLab Duo

Codewright se integriše sa vašim GitLab tokovom rada.
Spomenite `@codewright` u komentaru i Codewright će izvršiti zadatke unutar vašeg GitLab CI cevovoda.

---

### Funkcije

- **Problemi trijaže**: Zamolite Codewright da ispita problem i objasni vam ga.
- **Popravi i implementiraj**: Zamolite Codewright da popravi problem ili implementira funkciju.
  To će kreirati novu granu i pokrenuti zahtjev za spajanje s promjenama.
- **Secure**: Codewright radi na vašim GitLab pokretačima.

---

### Podešavanje

Codewright radi u vašem GitLab CI/CD cevovodu, evo šta će vam trebati da ga postavite:
:::tip
Pogledajte [**GitLab dokumente**](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/) za ažurirane upute.
:::

1.  Konfigurirajte svoje GitLab okruženje
2.  Postavite CI/CD
3.  Nabavite API ključ dobavljača AI modela
4.  Kreirajte nalog usluge
5.  Konfigurirajte CI/CD varijable
6.  Kreirajte konfiguracijski fajl toka, evo primjera:

    <summary>Konfiguracija toka</summary>

    image: node:22-slim

      - export GITLAB_TOKEN=$GITLAB_TOKEN_CODEWRIGHT

      - curl --silent --show-error --location "https://raw.githubusercontent.com/upciti/wakemeops/main/assets/install_repository" | bash
      - apt-get install --yes glab
      - echo "Configuring glab"
      - echo $GITLAB_HOST
      - echo "Creating Codewright auth configuration"
      - mkdir --parents ~/.local/share/codewright
      - |
        cat > ~/.local/share/codewright/auth.json << EOF
        {
          "anthropic": {
            "type": "api",
            "key": "$ANTHROPIC_API_KEY"
          }
        }
        EOF
      - echo "Configuring git"
      - git config --global user.email "codewright@gitlab.com"
      - git config --global user.name "Codewright"
      - echo "Testing glab"
      - glab issue list
      - echo "Running Codewright"
      - |
        codewright run "
        You are an AI assistant helping with GitLab operations.

        Context: $AI_FLOW_CONTEXT
        Task: $AI_FLOW_INPUT
        Event: $AI_FLOW_EVENT

        Please execute the requested task using the available GitLab tools.
        Be thorough in your analysis and provide clear explanations.

        <important>
        Please use the glab CLI to access data from GitLab. The glab CLI has already been authenticated. You can run the corresponding commands.

        If you are asked to summarize an MR or issue or asked to provide more information then please post back a note to the MR/Issue so that the user can see it.
        You don't need to commit or push up changes, those will be done automatically based on the file changes you make.

      - git checkout --branch $CI_WORKLOAD_REF origin/$CI_WORKLOAD_REF
      - echo "Checking for git changes and pushing if any exist"

        if ! git diff --quiet || ! git diff --cached --quiet || [ --not --zero "$(git ls-files --others --exclude-standard)" ]; then

            git commit --message "Codex changes"

          fi
        else

        fi
    variables:
      - ANTHROPIC_API_KEY
      - GITLAB_TOKEN_CODEWRIGHT

### Primjeri

Evo nekoliko primjera kako možete koristiti Codewright u GitLab.
:::tip
Možete konfigurirati da koristite drugu frazu okidača od `@codewright`.
:::

- **Objasnite problem**
  Dodajte ovaj komentar u izdanje GitLaba.

```
  @codewright explain this issue
```

Codewright će pročitati problem i odgovoriti jasnim objašnjenjem.

- **Reši problem**
  U izdanju GitLaba recite:

```
  @codewright fix this
```

Codewright će kreirati novu granu, implementirati promjene i otvoriti zahtjev za spajanje s promjenama.

- **Pregledajte zahtjeve za pridruživanje**
  Ostavite sljedeći komentar na zahtjev za spajanje GitLab-a.

```
  @codewright review this merge request
```

Codewright će pregledati zahtjev za spajanje i dati povratne informacije.
