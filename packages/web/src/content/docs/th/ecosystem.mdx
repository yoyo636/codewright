ชุดโครงการชุมชนที่สร้างขึ้นบน Codewright

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Codewright ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-codewright](https://github.com/awesome-codewright/awesome-codewright) และ [codewright.cafe](https://codewright.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
